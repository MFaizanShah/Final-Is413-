Pseudonym key

The system stores only pseudonymous codes. To match results back to students, upload a class list you already hold and download it with each student's code added. The file is processed in memory and nothing is stored; the request is recorded in the audit log.

Share the result only through approved channels with the lecturers of that course. Lecturers can also search for a student by real ID on their dashboard; the ID is hashed and never stored.
